# System Resource Monitor

## Функциональность

Легковесное WebUI-приложения для просмотра ресурсов системы. Предоставляет статистику о загрузке:
- CPU
- RAM

Обновление происходит раз в секунду.

## Архитектура решения

### Backend

- C++ бекенд, реализованный с учетом масштабирования.
- Система `Scanners` позволяет создавать сканеры с унифицированным интерфейсом для получения статистики о конкретной части системы
- Регистрация сканеров делает лёгкой их добавление: не требуется лишний модифицировать код.
- Для визуализации используется библиотека WebUI.

### Frontend

- HTML + Bootstrap для разметки страницы.
- TypeScript для обновления информации на странице.
- CSS для стилей
- Компиляция TS в JS перед стартом.

## Зависимости

- nlohnamm-json - встроено в решение (thirdparty)
- WebUI - встроено в решение (thirdparty)
- CMake
- npm
- typescript
- Браузер для просмотра WebUI (тестировался на Google Chrome)

## Сборка и Запуск

Перед сборкой установите зависимости фронтенда:

```
sudo apt update
sudo apt install npm
npm install
```

Выполните сборку:
```
make build
```

Запустите приложение:
```
make run
```
